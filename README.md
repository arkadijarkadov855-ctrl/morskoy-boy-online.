# Морской бой Online

## Запуск на своём компьютере
1. Установи Node.js 18 или новее: https://nodejs.org/
2. Распакуй архив и открой терминал в папке проекта.
3. Выполни `npm install`
4. Выполни `npm start`
5. Открой http://localhost:3000

## Игра через интернет
Нужен публичный хостинг, поддерживающий Node.js и WebSocket (например, Render или Railway).
1. Загрузи эту папку в новый GitHub-репозиторий.
2. Создай на выбранном хостинге новый Web Service из репозитория.
3. Build command: `npm install`
4. Start command: `npm start`
5. После публикации открой выданный HTTPS-адрес и отправь его другу. Один игрок создаёт комнату, второй вводит код.

Сервер хранит комнаты в памяти: при перезапуске хостинга незавершённые партии сбрасываются. Это стартовая версия без аккаунтов и постоянной статистики.
